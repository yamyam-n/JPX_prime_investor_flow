# JPX Prime Investor Flow v1.7

## v1.7の修正点
- JPX旧フォーマットの週次表を「1行=1週」と仮定する処理を廃止。
- 日付行の次にExcelリンク行が続く `rowspan` / 複数TR構造に対応。
- 次の日付行までのリンクを同一週として束ね、`stock_val` / `val` のExcelを金額ファイルとして選択。
- `val` がURLに見えない場合でも、同週のExcel候補が複数ならJPX表の並び（株数→金額）に従い後側を候補にする。
- ダウンロード後はContent-TypeだけでなくXLS/XLSXのファイルシグネチャを検証。
- Primeシートを明示探索し、金額単位をExcel内表記から億円換算。
- 週次 / 月次切替、iPhone向け1カラム表示を維持。

## 根本原因
旧版は「日付が書かれた<tr>の中にExcelリンクもある」と仮定していました。
JPX旧形式では1週間の表示が複数行に分かれ、日付セルがrowspan、Excelリンクが続く別<tr>になる場合があります。
そのため、日付行だけを解析すると週は見つかるのにExcelリンクが0件になっていました。
